# Changelog

## 1.0.2

- A drag-to-Applications DMG, verified after mounting and copying the app.
- New Howr LCD chime logo and a complete macOS app iconset.
- Separate Homebrew and terminal release assets for aggregate download counts.
- Public contribution instructions, issue/PR templates and download statistics tool.

This release is still ad-hoc signed, not Apple-notarized.

## 1.0.0

First public release for macOS 14+, on Apple silicon and Intel.

- Menu-bar chimes every 15, 30 or 60 minutes, synthesized sounds, macOS alerts and spoken time.
- Active hours, weekdays, pause, skip, volume and optional quiet rules.
- Daylight and backlit LCD interface with keyboard controls and launch at login.
- Single-agent lock, validated preferences, authoritative UI settings snapshots, bounded IPC and serialized audio replacement.
- MIT source, universal ZIP, SHA-256 checksums and a custom Homebrew cask.

This release is ad-hoc signed, not Apple-notarized. First launch may require approval in System Settings. See the README.
